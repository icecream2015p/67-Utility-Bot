# 67-Utility-Bot

個人用のDiscordユーティリティBotです。サーバー・DM・ユーザーインストールのどこからでもスラッシュコマンドを使えます。

## コマンド一覧

| コマンド | 説明 |
| --- | --- |
| `/dentaku [式]` | 電卓。式を省略するとボタン式の電卓、式を渡すとその場で計算 |
| `/memo list` | 登録されているメモをすべて表示 |
| `/memo add 内容: [位置:]` | メモを追加（位置は「上から何番目か」、省略すると一番下） |
| `/memo delete 番号:` | 指定した番号（上から何番目か）のメモを削除 |
| `/help` | 各コマンドの説明を表示 |

### 電卓 `/dentaku`

- 式を省略: ボタン式の電卓を表示（`=` で計算、`C` でクリア、`⌫` で1文字削除）。10分操作がないと無効になります。
- 式を指定: `(1 + 2) * 3` のように入力すると、その場で計算して結果を返します。
- 使える演算: `+` `-` `*` `/` `//` `%` `**` と括弧。全角の `×` `÷` `＋` `（）`、全角数字、カンマ区切り（`1,000`）にも対応しています。
- 計算は `ast` で数式のみを評価するため、任意のコードは実行されません。0除算・巨大な結果・長すぎる式はエラーメッセージを返します。

### メモ `/memo`

メモは**ユーザーごと**に保存され、他の人のメモは見えません。

- `位置` / `番号` は「上から何番目か」を表す1始まりの番号です（`/memo list` の表示番号と同じ）。
- `/memo add 内容:牛乳を買う` … 一番下に追加
- `/memo add 内容:重要 位置:1` … 1番目（先頭）に挿入
- `/memo delete 番号:2` … 2番目のメモを削除（番号は入力候補からも選べます）
- メモは1件1000文字まで。一覧が長い場合は自動で複数メッセージに分割されます。

## セットアップ

```bash
pip install -r requirements.txt
export DISCORD_BOT_TOKEN="Botのトークン"
python main.py
```

Renderなどで動かす場合は、環境変数に `DISCORD_BOT_TOKEN` を設定してください。`0.0.0.0:$PORT` で簡易Webサーバーを起動するため、Webサービスとしてデプロイできます。

### メモの保存先

`memos.json`（`main.py` と同じディレクトリ）に保存されます。保存先を変えたい場合は環境変数 `MEMO_FILE` にパスを指定してください。

> ⚠️ Renderの無料プランなど、ファイルシステムが一時的な環境では、再デプロイや再起動でメモが消えることがあります。永続化したい場合は `MEMO_FILE` を永続ディスク上のパスに指定してください。
