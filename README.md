# 67-Utility-Bot

個人用のDiscordユーティリティBotです。サーバー・DM・ユーザーインストールのどこからでもスラッシュコマンドを使えます。

## コマンド一覧

| コマンド | 説明 |
| --- | --- |
| `/dentaku [式]`<br>`/calc [式]`<br>`/calculator [式]` | 電卓（3つの名前はどれも同じ）。式を省略するとボタン式の電卓、式を渡すとその場で計算 |
| `/reminder add 日時: 内容:` | 指定した日時にDMで通知（例: `30分後`） |
| `/reminder list [完了済み:]` | 登録済みのリマインダーを期限順に表示 |
| `/reminder delete 番号:` | 指定したIDのリマインダーを削除 |
| `/todo add 内容: [期限:] [優先度:]` | TODOを追加（期限を指定すると期日にDM通知） |
| `/todo list [完了済み:]` | TODOを優先度・期限順に一覧表示 |
| `/todo done 番号: [戻す:]` | TODOを完了／未完了に戻す |
| `/todo delete 番号:` / `/todo clear` | TODOを削除／完了済みをまとめて削除 |
| `/todo dashboard` | TODOの概要（未完了・今日締切・期限切れ） |
| `/memo list` | 登録されているメモをすべて表示 |
| `/memo add 内容: [位置:]` | メモを追加（位置は「上から何番目か」、省略すると一番下） |
| `/memo edit 番号: 内容:` | 指定した番号のメモを書き換え |
| `/memo search キーワード:` | キーワードを含むメモを検索 |
| `/memo delete 番号:` | 指定した番号（上から何番目か）のメモを削除 |
| `/help` | 各コマンドの説明を表示 |

## TODO `/todo`

やることを管理します。メモ（自由記入）と違い、**完了／未完了**と**期限**を持ちます。

- `/todo add 内容:請求書を送る 期限:明日 10:00 優先度:高` … TODOを追加（`期限` と `優先度` は任意、優先度は `高` `中` `低`）
- 期限を指定すると、**その時刻にDMでリマインド**します（通知は1回だけ）。
- `/todo list` … 未完了を先に、**優先度が高い順 → 期限が近い順**で表示。`❗` は期限切れ、`✅` は完了。
- `/todo done 番号:3` … 完了にする（`戻す: True` で未完了に戻す）。最後の1件を終えるとお祝いメッセージが出ます。
- `/todo delete 番号:3` … 削除 / `/todo clear` … 完了済みをまとめて削除
- `/todo dashboard` … 未完了・完了・今日締切・期限切れの件数と未完了リストをEmbedで表示

期限の書き方はリマインダーと同じです（次の表を参照）。

## リマインダー `/reminder`

指定した日時に**DMで通知**します。DMが送れない場合は実行したチャンネルに通知し、どちらも失敗した場合は5回まで再試行してから諦めます（TODOの期日通知も同じ30秒間隔のループで処理します）。

日時の指定方法:

| 書き方 | 意味 |
| --- | --- |
| `10:30` | 今日の10:30（過ぎていれば明日） |
| `明日 9:00` / `明後日 9時` / `今日 20:00` | 指定した日の時刻 |
| `2026/11/20 10:30` / `11/20 10:30` / `11月20日 10時30分` | 日付＋時刻（年を省略すると今年。過ぎていれば来年） |
| `30分後` / `2時間後` / `3日後` / `1週間後` | 現在時刻からの相対指定 |

- タイムゾーンは既定で `Asia/Tokyo`。変えたい場合は環境変数 `BOT_TIMEZONE` に名前（例: `UTC`）を指定してください。
- 1年先まで登録できます（`/reminder delete 番号:` のIDは入力候補からも選べます）。
- DMを受け取れるように、Discordの「プライバシー設定」→「サーバーメンバーからのDMを許可」をオンにしておいてください。

### 電卓 `/dentaku` `/calc` `/calculator`

- `/dentaku`・`/calc`・`/calculator` はすべて同じ電卓です（好みの名前でどうぞ）。
- 式を省略: ボタン式の電卓を表示（`=` で計算、`C` でクリア、`⌫` で1文字削除）。10分操作がないと無効になります。
- 式を指定: `(1 + 2) * 3` のように入力すると、その場で計算して結果を返します。
- 使える演算: `+` `-` `*` `/` `//` `%` `**` と括弧。全角の `×` `÷` `＋` `（）`、全角数字、カンマ区切り（`1,000`）にも対応しています。
- 計算は `ast` で数式のみを評価するため、任意のコードは実行されません。0除算・巨大な結果・長すぎる式はエラーメッセージを返します。

### メモ `/memo`

メモは**ユーザーごと**に保存され、他の人のメモは見えません。

- `位置` / `番号` は「上から何番目か」を表す1始まりの番号です（`/memo list` の表示番号と同じ）。
- `/memo add 内容:牛乳を買う` … 一番下に追加
- `/memo add 内容:重要 位置:1` … 1番目（先頭）に挿入
- `/memo delete 番号:2` … 2番目のメモを削除（番号は入力候補からも選べます）
- メモは1件1000文字まで。一覧が長い場合は自動で複数メッセージに分割されます。
- `/memo search` は大文字・小文字を区別しません。

## セットアップ

```bash
pip install -r requirements.txt
export DISCORD_BOT_TOKEN="Botのトークン"
python main.py
```

Renderなどで動かす場合は、環境変数に `DISCORD_BOT_TOKEN` を設定してください。`0.0.0.0:$PORT` で簡易Webサーバーを起動するため、Webサービスとしてデプロイできます。

### データの保存先

- メモ: `memos.json`（環境変数 `MEMO_FILE` で変更可）
- リマインダー: `reminders.json`（環境変数 `REMINDER_FILE` で変更可）
- TODO: `todos.json`（環境変数 `TODO_FILE` で変更可）

いずれも `main.py` と同じディレクトリに作成されます。

> ⚠️ Renderの無料プランなど、ファイルシステムが一時的な環境では、再デプロイや再起動でメモ・リマインダー・TODOが消えることがあります。永続化したい場合は `MEMO_FILE` / `REMINDER_FILE` / `TODO_FILE` を永続ディスク上のパスに指定してください。また、無料プランはスリープするとリマインダーの通知も止まります（常時稼働には有料プランか外部のcronでの起こしが必要です）。
